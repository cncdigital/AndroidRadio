# Radio Sindical 0.10.34 candidate: listener capsule cadence
- Five 48dp icon-only controls in the main player: shuffle, favorite, audio, tastes and capsule frequency. The capsule control also appears in fullscreen. Icons have accessible labels and tooltips; the capsule control announces its cadence and changes its icon and selected styling. Fullscreen karaoke keeps a dynamic action label for TalkBack.
- The frequency preference lives on the device and defaults to one regular capsule after every five completed songs. Frequent mode allows one regular capsule at each new song start, including the first and manual track selection. A pause/resume or a rejected clip does not retry that song. Switching cadence affects the next unconsumed music entry; it does not interrupt a clip. Manual skips and commercial breaks do not advance the count.
- A fact is due after every nine completed songs. Where both types are due, request exactly one clip: fact first, fallback to a regular clip only if a playable linked fact is unavailable. In sparse mode the first such collision is after song 45. An unavailable recording means music only; no recording is generated.
- The opt-in server endpoint must be deployed first. Specify capsuleSlot=regular, fact or fact-or-regular; a successful response must echo it in x-radio-capsule-slot and provide x-radio-kind. The server should prefer available, valid ElevenLabs assets within the selected type. Old server responses with absent echo are safely skipped.
- Unchanged protections: only a complete, validated local clip can start; normal music volume persists until voice plays, and clips already interrupted do not resume. No previously saved capsule is changed; there is no prewarm request on a non-capsule boundary.
- Android retains up to 12 recently audible IDs and exact server template keys in service memory. Only the first actual playback-start event records a capsule; preloading, missing metadata, expiration, cancellation and rejected clips do not. Requests send only the public IDs and keys as recent and templates. The player also skips an immediate duplicate ID or template if returned.
