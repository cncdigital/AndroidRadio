# Phone-only external YouTube pilot

- Only exact catalog triples are enabled: 75, Oye Mujer / Raymix; 384, Voy a Llenarte Toda / José José. José José is labeled as a live video, not as an exact match to the studio recording. No link is searched, generated from title, or accepted as player input.
- The pilot appears as an added transient carousel position on a verified song only, between the last background and the album cover. Swipe in either direction across that point. Cover and existing lyrics remain shown on the phone; the explicit watch button is below the artwork, or in existing fullscreen chrome. A swipe alone neither pauses the radio nor accesses YouTube.
- A tap asks the local phone service to pause the exact still-current song and cancel any running or pending capsule. The activity waits for the service acknowledgement and for the controller to reflect paused playback before dispatching a browsable ACTION_VIEW with the exact allowlisted watch URL. Failing either check does not launch. No seek or autoplay is performed; closing the external player returns to the prior art and the user may resume the same song from its existing playhead and synchronized lyrics.
- The video preview is not persisted; swiping away, a changed song, leaving/rotating the activity suppress a delayed launch. Existing Android Auto/Automotive/notification commands do not gain an action; there is no inline or background YouTube player.
- Device check: with Raymix playing and a capsule audible, swipe then explicitly open the YouTube button. Check no YouTube before tap, radio and capsule pause before handoff, lyric/timestamp retained on return, and no auto-resume. Repeat with the live version label, unmatched track, cancellation/rotation during acknowledgement, and no activity able to handle the link. Check the two directions in fullscreen, leaving existing lyric dragging intact. Full Gradle and device validation required.
